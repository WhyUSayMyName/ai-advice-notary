# Мои правки

Сюда складывайте изменённые версии макетов. Папка ваша — правила простые.

**Удобнее всего сохранять имя файла прежним.** Тогда `my/brand-identity.html`
и `../brand-identity.html` — это до и после, и я вижу разницу сразу. Но можно
и переименовывать, если так понятнее: `brand-v2.html`, `заставка-ярче.html` —
просто скажите, какой файл смотреть.

**Ничего не сломается.** Файлы отсюда никуда не подключены: приложение их не
читает, сборка не трогает. Экспериментируйте свободно — оригиналы в папке
уровнем выше останутся целыми.

**Как показать мне:** «посмотри `design/my/brand-identity.html`». Прочитаю,
разберусь, что изменилось, и дальше по вашему желанию — перенесу в приложение,
опубликую по ссылке или доработаю вместе.

Пара мелочей, чтобы не спотыкаться:

- если файл начинается сразу с `<title>` — так и оставьте, это формат для
  вкладки дизайна (подробнее в `../README.md`);
- новый цвет добавляйте в оба набора тем — `:root` и `:root[data-theme="light"]`,
  иначе в одной из тем он пропадёт;
- в вордмарке не убирайте `gradientUnits="userSpaceOnUse"` — без него исчезает
  буква I.
